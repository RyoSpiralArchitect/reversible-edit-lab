# Factual edit → rollback → next edit: fixed pilot protocol

Use the authors' ROME and MEMIT implementations from kmeng01/memit commit
80426fd9316cf9a50c5ba15e0912f2c2c5bfe84b. The upstream MIT license and exact
CPU/Transformers compatibility patch are retained in provenance/factual-edit/.
Prepare with scripts/prepare_factual_upstream.py; no upstream optimization math
is replaced. Changes replace CUDA with CPU, handle Tensor block outputs, read
input_ids explicitly for subject indices, and resolve globals.yml by location.

Model: the same pinned GPT-2 FP32 checkpoint as PR #2. This is a bounded small
model adaptation, not a reproduction of the papers' GPT-2 XL/GPT-J benchmarks.
ROME layer 5; MEMIT layers 4,5,6. Subject-last lookup, final-layer loss,
20 optimizer iterations maximum, Adam lr .5, KL .0625, weight decay .5.
Clamp norm factor 4 for ROME and .75 for MEMIT. Fixed contexts: plain prompt,
"Today, ...", and "In a report, ...". No tuning based on the results.

Use actual uncentered second moments of c_proj inputs over 16 declared neutral
sentences generated by the script; freeze them on the base model. Add ridge
.01 × mean diagonal; MEMIT preservation multiplier 1000. This small calibration
is deliberately distinct from the upstream 100,000-document Wikipedia moments.
The upstream dataset loader is disabled; explicit frozen covariance providers
are used. Save matrices, token counts, ridge, and hashes.

Counterfactual requests are experimental targets, not asserted world facts:
ROME A: France capital → Rome. MEMIT A: France → Rome and Japan → Paris,
jointly optimized and distributed across three layers. Both B: Italy → Tokyo.
ROME and MEMIT differ in A batch size; do not infer comparative algorithm quality.
For each algorithm compute B freshly from base as a reference. Then compute A,
restore with checkpoint/delta/exact corrected delta, and recompute all B targets
and factors from that restored model with a fresh optimizer and seed 7. No
cached B factors or target vectors are reused. Frozen contexts/covariance are
shared reference metadata. Exact and checkpoint paths must match base and B
reference in full model-state digest and all probe logits.

Evaluate rewrites, one held-out paraphrase per country, Germany locality and an
unrelated sky prompt. Save target probability, rank, top token, full logit arrays
and optimization traces. Report failures to achieve edited target independently
of rollback exactness. No statistical generalization claim from this panel.

Compare actual layer record bytes, parent-process build time, independent NumPy
undo worker time/RSS. Parent build includes a live model; its peak RSS is not
compared to the previous worker-only build benchmark. Weight factors retain the
upstream arithmetic/dtype; correction covers prediction and storage differences.
Undo receives only edited layer and its declared record. Checkpoint legitimately
contains old weights. Store binaries under ignored work/ with public hashes.

Run after preparing the compatibility copy:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
.venv/bin/python -I scripts/factual_edit_chain.py --model-dir work/models/gpt2 \
  --upstream work/upstream-memit-cpu --out results/my_factual_chain
```

This optional script requires Python 3.11+, Torch, Transformers and matplotlib.
